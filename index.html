Lyrics

Lyrics can be used on their own. One document can hold all your lyrics. To update file-based lyrics, import the revised file.

Lyrics document format

Use Heading 1 for each Artist — Song title, and normal text underneath for the lyrics. Use Artist — Song headings to build the artist/song list. If you also import chords, matching names share the lyrics. One lyrics entry can serve multiple keys of the same song. In Google Docs, choose File → Download → Microsoft Word (.docx) for a copy you can import offline. Background highlighting is preserved. The first two highlight colours use your selected colour scheme; additional colours retain their original background with readable text. Older .doc and PDF files are not supported.

Google connection

Google actions need an internet connection. File imports do not require Google sign-in. Importing a file replaces that collection’s Google connection; the other collection is unaffected.
