Lyrics document format

Use Heading 1 for each Artist — Song title, and normal text underneath for the lyrics. Names must match the chords library. One lyrics entry can serve multiple keys of the same song. In Google Docs, choose File → Download → Microsoft Word (.docx) for a copy you can import offline. Older .doc and PDF files are not supported.

Google connection

Google actions need an internet connection. File imports do not require Google sign-in. Importing a file replaces that collection’s Google connection; the other collection is unaffected.
